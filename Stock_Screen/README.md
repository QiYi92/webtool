# Stock_Screen

工具站“投资走势预测”使用的 A 股策略模块。该模块随 `galileocat-webtool` 仓库发布，运行时由 Docker Compose 只读挂载到 backend 容器的 `/opt/stock_screen`。

## 内容

- `screen_bowl_shape.py`：股票筛选逻辑。
- `configs/*.json`：可在工具站中选择的策略配置。
- `excel_exporter.py`：原始 Excel 报告导出。
- `test_*.py`：策略模块单元测试。

## 维护约束

- 新增策略时，在 `configs/` 新增合法文件名的 JSON 文件；工具站会自动发现它。
- 不要提交 `data/`、缓存、虚拟环境或真实运行报告。
- backend 容器使用 `/opt/stock_screen`，本地直接运行 backend 时默认解析仓库内的 `Stock_Screen/`。不要再依赖或创建 `Stock_Screen_demo` 同级目录。

## 找底部模型（default_bottom）

在投资走势预测的策略下拉框选择“找底部模型”。它是独立策略，原默认策略和定时策略不变。
沿用原股票池、板块及上市时间设置；一年趋势、放量突破、碗型开关不适用于此模型，数据和平台检查不可关闭。

`configs/default_bottom.json` 中的 `bottom` 参数定义：最近 250 日的年内位置不超过 30%、距年内高点回撤至少 20%；最近 5 日之前的 40 日为平台，日内高低振幅不超过 18%、收盘振幅不超过 12%、归一化回归斜率绝对值不超过 6%；后半平台最低收盘不低于前半的 97%，最近 5 日最低收盘不低于平台下沿的 98%，最新收盘不超过平台下沿的 115%。

通过基础底部条件后，同时满足最新收盘高于平台收盘价 80% 分位、收盘 > MA10 ≥ MA20、MA10 比 5 日前上升、5 日均量至少为平台末 20 日均量的 1.2 倍、5 日涨幅为 2%–10%，标记“出现转强”（`bottom_v1_strength`）。其余股票还必须通过下述 `sideways_v2` 条件，才可标记“横盘未突破”。

使用前复权日线，不回退不复权行情；北京时间 15:00 前排除当日日线。检查数据缺失、重复日期、非法价格、平台和信号期零量。Excel 按两个阶段分表，并在“模型指标”中记录筛选日期和原始指标。年内位置、回撤、振幅、斜率和涨幅以比例保存（0.3 表示 30%），量比以下限 1.2 这类倍数保存。

### 横盘未突破 v2：五年低位与低活跃度

只使用价格和量能，不判断财务估值、盈利质量或实际公众关注度。`sideways` 参数独立于原 `bottom` 参数；转强分支不会请求五年数据，原碗底模型不受影响。

| 环节 | 必须满足的条件 |
| --- | --- |
| 长期数据 | 上市满5个自然年；窗口从筛选截止日向前5年，至少1100根日线，首日距窗口起点不超过10个自然日，末日与短期行情截止日相同 |
| 五年低位 | 最新价经验分位≤20%；平台收盘中位数≤五年收盘20分位；最新价≤五年10分位×115%，且≤五年中位价×85% |
| 平台稳定 | 高低振幅≤12%，收盘振幅≤8%，归一化斜率绝对值≤3%；后20日下沿≥前20日下沿×98%，最近5日下沿≥平台下沿×99% |
| 未离平台 | 最新收盘≤平台最低收盘×108%，且≤平台最高收盘×101% |
| 交易热度 | 最近20日平均换手≤此前不重叠100日平均换手×70%；20日换手中位数0.1%–1%，单日换手≤3%，5日平均换手≤20日平均换手×1.3 |
| 流动性 | 20日成交额中位数≥2000万元；最近120日成交量、换手率、成交额均为正 |

经验分位为收盘价不高于被比较价格的天数占比；价格分位数采用线性插值。仍先满足原250日底部条件。零值/负值量能在“长期数据”有效性检查时提前排除；缺失值、接口错误、覆盖不足和复权异常属于“未验证”，与规则淘汰分开统计。每只股票只计首个失败环节。

五年行情通过项目内 AKShare 适配层获取前复权日线。长短行情最后45日须对齐，允许统一价格缩放以及不超过0.2%加0.01元的报价舍入差异，不允许不同形态拼接。以短期行情最后一个已完成交易日为实际截止日，排除其后数据。

缓存位于 `CACHE_DIR/sideways/`，按股票、窗口、截止日、复权口径和当前 AKShare 行情方案区分，原临时缓存清理不删除该子目录。缓存与供应商数据保留百分数换手率，进入模型时除以100；成交额为元。无效字段不填零，也不倒推历史流通股本。

Excel“模型指标”增加五年价格分位、平台价格分位、相对长期中位价、换手收缩比、20日换手率中位数、20日成交额中位数和规则版本。比例数0.005表示换手率0.5%；“出现转强”未执行的五年指标留空。前端阶段字段与数据库不变，已有任务不重新标记。

### 按原任务名单复核

```sh
python Stock_Screen/verify_sideways_task.py backend/data/investment_prediction/2bf078c8-11f4-4573-969b-3df28007d754.xlsx --output backend/data/investment_prediction/sideways_v2_review_20260922.json --cache-dir backend/data/investment_prediction/cache --single-attempt
```

此命令只读取原报告“模型指标”中的“横盘未突破”，使用每只股票原筛选日和原上市日期；只补验新增条件，不读取之后的K线，也不改写原文件。`--single-attempt` 仅限制复核批次请求次数，不影响线上筛选重试。

2026-09-23 对原任务复核：总命中133只，其中横盘未突破131只、出现转强2只。131只均因东方财富断开连接（`RemoteDisconnected`）未取得五年行情，统计为**保留0、确认淘汰0、未验证131**；各规则淘汰数均为0，仅代表没有完成验证，不能据此判断规则宽严。代表样本包括贝特瑞（920185）、中科软（603927）、晨光股份（603899），均为未验证。待数据源恢复后可重跑上述命令；没有为凑数量调整阈值。


### AKShare 行情适配与版本更新

股票列表、个股资料、历史日线和量能字段统一经 `akshare_data.py` 适配。当前 AKShare 行情方案使用腾讯实时股票列表、交易所上市资料、巨潮个股资料、腾讯沪深日线和新浪北交所日线。适配层把腾讯总市值从亿元换算为元、日线换手率从比例换算为百分数，再交给原筛选逻辑。国内行情域名默认直连，其他网络请求保留系统代理；需要让行情也经过代理时可使用 `--use-proxy`。网络连接连续三次失败或上游接口超时后任务停止，不使用缓存股票池替代当日列表；项目代码不直接请求这些上游接口。股票池 CSV 只保留作当日审计。

后端每天北京时间 06:00 查询 AKShare 的最新 PyPI 版本和 GitHub 发布说明，并对当前版本运行行情冒烟检查；当天尚未检查时，启动后也会在后台补查。发现新版本时在独立虚拟环境安装候选版，验证股票列表、个股资料、短期日线和五年历史覆盖；候选版失败时保留已激活版本。验证通过后等待预测任务空闲，再切换版本并触发后端容器重启；重启导入检查失败时回滚到上一版本。检查时间、当前/最新版本、接口状态和升级状态显示在“模型预测”卡片右侧，并持久化在 `backend/data/investment_prediction/akshare/`。版本发布页不可访问时仍单独记录行情接口检查结果。

行情接口不可达、字段变化或历史覆盖不足时，状态会记录失败原因，预测任务按数据故障停止。修复网络或等待候选 AKShare 版本更新后再执行，不把接口故障算作筛选淘汰。
